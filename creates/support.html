Support

Keep the work moving.

Project access

The standalone workspace and Nexum Personal use the same nxp_creative_v2 project format. Export the project package before moving devices or resolving a sync conflict.

Provider readiness

Media, narration and live-avatar actions depend on the selected provider being connected. The Providers view shows current server-side readiness without exposing credentials.

Sync conflicts

NuaCreates uses optimistic version checks. If a project changed elsewhere, export both copies before choosing which version to continue.

Paid actions

Image, video, narration and presenter jobs require an explicit start. A failed or unavailable provider should not be described as a completed render.

Contact

Use the Nua support route. Include the app version, operating system and exact visible error. Do not send provider keys or private project files unless support explicitly requests a safe upload.
