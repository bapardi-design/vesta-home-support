Privacy

Creative work belongs to its creator.

This page describes the current NuaCreates product boundary. Provider-specific processing applies only when you explicitly start a provider action.

Project data

Projects can contain drafts, chapters, scenes, character notes, visual references, editorial decisions and production metadata. Device-local project state remains on that device unless you explicitly use cloud sync or export it.

AI and media providers

When you start an AI request, NuaCreates sends the bounded input needed for that request to the selected provider. Provider, model, job state and available cost metadata remain visible. NuaCreates does not silently publish creative work.

Voice

Live voice receives bounded creative context for the current session. It does not publish, start paid media generation or send a business handoff by itself.

Exports and deletion

You can export the portable project package. Local project data can be erased from the application settings. Cloud-synced copies require an authenticated deletion request.

Contact

Use the NuaCreates support page for privacy and deletion requests.
